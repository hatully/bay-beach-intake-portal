# Beach Veterinary Care — Smart Intake & Triage Portal

A modern, mobile-first patient intake and triage web application designed for independent veterinary clinics and animal hospitals in coastal communities.

## 🚀 Key Features
* **Sub-Second Mobile Load:** Built on zero-bloat vanilla HTML/CSS/JS ready for global CDN deployment via Vercel or GitHub Pages.
* **3-Step Triage Flow:** Replaces 40-field single page scroll with an intuitive progressive intake.
* **Fear-Free & Feline-Friendly:** Built-in low-stress handling preferences.
* **Zero PII Intrusiveness:** Eliminates upfront demands for Driver's License numbers and legal wall-of-text checkmarks.

## 🛠️ Deploy to Vercel
```bash
vercel deploy --prod
```
